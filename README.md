# Chat-app

Aplikacja czatu klient-serwer umożliwiająca rejestrację i logowanie użytkowników, tworzenie oraz dołączanie do pokoi konwersacyjnych, wysyłanie wiadomości w czasie rzeczywistym oraz zarządzanie kontem. Klient to aplikacja desktopowa Windows z interfejsem WinUI 3 (.NET 8), serwer to konsolowa aplikacja .NET obsługująca połączenia TCP i komunikująca się z bazą MongoDB Atlas. Projekt zrealizowany w ramach przedmiotu "Programowanie obiektowe 2".
